# Campaign editor requirement traceability

Design review only. “Demonstrated” means the local prototype, not production delivery.

| Recommendation                                 | Design/prototype evidence                                                                                      | Production gate                                                                      |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Focus only on campaign creation/editing        | New files under `docs/prototypes/campaign-editor/`, isolated server; no production UI edits                    | Keep dashboard/overview/admin out of implementation scope                            |
| Audit before replacing production              | `CAMPAIGN_EDITOR_UX_AUDIT.md` inspects model, permissions, renderer and save controller                        | No replacement before founder approval                                               |
| Realistic interactive prototype                | Six-section Fieldnotes starter, Fresh launch variant, blank start                                              | Approved design first                                                                |
| Editable campaign name                         | Topbar field, local saving/saved/failure feedback                                                              | Connect existing separate rename endpoint; retain its known concurrency limitation   |
| Undo/redo                                      | Toolbar, shortcuts, grouped typing and compound block/style changes                                            | Session history plus existing autosave acknowledgments                               |
| Viewport controls and immersive preview        | 390/768/1200 targets, same document, fit and zoom, editor return                                               | Shared production renderer; no device copies                                         |
| Publish placeholder                            | Disabled desktop control with explanation                                                                      | No publishing implementation                                                         |
| Searchable categorized library with thumbnails | All 12 approved types, search, filter, schematic thumbnails                                                    | Reuse library registry and limits                                                    |
| Ordered Layers with visibility and drag        | Explicit handles, hidden state, pointer reorder verified at desktop/mobile viewport                            | Real touch/cancellation/long-list testing                                            |
| Media placeholder                              | Media panel and three labelled bundled SVG samples                                                             | No asset service or uploads until media phase                                        |
| Dominant canvas and selection                  | Center workspace, hover/selected outlines, contextual toolbar and synchronized inspector                       | Preserve safe renderer boundary                                                      |
| Direct inline editing                          | Plain text canvas fields; inspector reflects edits; pasted text sanitized                                      | IME, selection and native undo regression tests                                      |
| Insertion controls                             | Between-section plus controls and selected insertion destination                                               | Transactional add, limits, focus restoration                                         |
| Library drag to canvas                         | Pointer-captured card, labelled ghost and insertion line; browser verified                                     | Touch gestures and accessibility acceptance                                          |
| Canvas section drag                            | Section drag handles use same pointer controller and target calculation                                        | Additional cross-frame, zoom and touch acceptance tests                              |
| Content/Layout/Style inspector                 | Selected block fields; layouts for Hero/CTA; tone/spacing; global theme labelled                               | Versioned presentation proposal requires separate approval                           |
| Duplicate/hide/delete                          | Contextual canvas and inspector actions; deletion undo                                                         | Stable IDs, media limits and schema validation                                       |
| Accessible movement                            | Labelled inspector arrows, Alt+Up/Down on section/handle                                                       | Keyboard/browser acceptance                                                          |
| Mobile sheets                                  | Canvas/Add/Layers/Properties navigation; bottom sheets; background inertness, close/escape and Tab containment | Physical touch and assistive technology review                                       |
| Starter or blank campaign                      | Three chooser cards; no hard-coded campaign types                                                              | Integrate existing create service and guarded replacement                            |
| Required ten-step journey                      | Browser exercised blank → Hero → inline heading → sample → layout/color → CTA → drag → preview → undo/save     | Repeat end to end with production save controller                                    |
| Professional visual system                     | Semantic CSS tokens, shared SVG icon helper, consistent controls, visible states, reduced-motion support       | Contrast/focus/touch audit across every block/style                                  |
| Responsive 320px+                              | Captures at 320/390/768/1440 and responsive panels                                                             | Broader browser/real-device acceptance                                               |
| Autosave/conflict reliability                  | UI prototype shows local saves, failure/retry and version choice; production controller/service untouched      | Reuse existing serialized/idempotent/revision-checked saves, never prototype storage |
| Preserve all schemas and data                  | Production schema reused for content validation; proposed appearance stored separately                         | Additive approved versioning; identity-preserving conversion tests                   |
| No paid/external/media/publishing work         | No dependencies added, no API client, loopback-only static prototype                                           | Phase 3 remains blocked                                                              |
| Audit/spec/screenshots/checklist/plan          | Five linked documents plus captured review screens                                                             | Stop and request interaction approval                                                |

Deliberate adaptations: a labelled review strip separates design-only actions from future product chrome; mobile omits the unavailable Publish control; secondary move controls stay in Properties; the native preview viewport remains a scaled responsive canvas rather than free positioning. These preserve the requested structured campaign-builder direction.
